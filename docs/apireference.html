from dexweb import dexweb
dexweb.Dexweb().publish()

class Dexweb()

Dexweb is a Python class in dexweb.dexweb with web services for a dex. Dexweb() takes no arguments and reads config.json in the dex root. Dexweb().publish() publishes the dex built in gen/ as set by publish in config.json, and returns True if the dex was published and False if not. See Publishing Dex Online.

See dexweb.py for class Dexweb
